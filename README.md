 🛍️ Retail Analytics Project

This project analyzes retail sales data to uncover actionable insights into product performance, customer behavior, and seasonal trends.  
It demonstrates an end‑to‑end workflow: **SQL for querying**, **Python for ETL & feature engineering**, and **Power BI for interactive dashboards**.


 Tech Stack
- **SQL (MySQL)** → Data extraction & transformation  
- **Python (pandas, numpy, matplotlib, seaborn)** → ETL pipeline, feature engineering, visualization  
- **Power BI** → Interactive dashboards & storytelling  


 Key Insights
- Identified top‑performing product categories  
- Seasonal sales trends and demand forecasting  
- Customer segmentation for targeted marketing  
- Revenue contribution by region/store
